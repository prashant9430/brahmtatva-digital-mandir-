📋 Admin Panel Instructions

🎵 Mantra Management

  1. Category select करें
  2. सभी mantras की list दिखेगी
  3. नया mantra add करने के लिए form भरें
  4. Sanskrit, Hindi meaning, और benefits add करें
  5. "Add Mantra" button दबाएँ
  6. Data automatically save हो जाएगा (Local Storage में)

🕯️ Aarti Management

  1. सभी aartis की list दिखेगी
  2. नई aarti add करने के लिए form भरें
  3. Aarti के गीत को हिंदी में लिखें
  4. हर line के बाद Enter दबाएँ
  5. "Add Aarti" button दबाएँ

📖 Granth Management

  1. सभी granths की list दिखेगी
  2. नई granth add करने के लिए सभी details भरें
  3. PDF filename को सही format में दें (granth-name.pdf)
  4. PDF file को /pdfs/ folder में रखें
  5. "Add Granth" button दबाएँ
  6. Website को refresh करें

💾 Data को Export/Backup करें

  1. Browser का DevTools खोलें (F12)
  2. Console tab पर जाएँ
  3. यह command चलाएँ: console.log(JSON.stringify(localStorage, null, 2))
  4. Output को copy करके safe रखें

⚠️ Important Notes

  • Data Local Storage में save होता है (browser में)
  • Different browser में data नहीं दिखेगा
  • Browser cache clear करने से data delete हो सकता है
  • Backup के लिए regularly export करें
  • JSON files को directly edit भी कर सकते हैं
